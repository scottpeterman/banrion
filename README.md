# banrion
**Banrion** — Irish for *queen*, from *ban* (woman) + *rí* (king). Pronounced roughly BAN-ree-un.  A two-player internet chess game rendered as a glowing wireframe, with a computer opponent for solo play. No server, no accounts, no build step. Two people open the same HTML file, one hosts, the other pastes in a code, and they play.
